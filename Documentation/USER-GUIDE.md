# User Guide

## Getting Started

1. Open Exzera Tool on a supported Windows computer.
2. Connect a device that you own or are authorized to service.
3. Select the detected port when a port-based function is required.
4. Choose the appropriate device category.
5. Select the required function and follow the messages shown in the device console.
6. Wait for a clear success or completion message before disconnecting the device.

## Reading Device Information

1. Select the appropriate entry from the port list.
2. Choose **Read Info**.
3. Review the information and status messages in the device console.
4. Use the refresh control if the device or port is not listed.

## Running a Security Scan

1. Open the Android area and choose **Virus Scan**.
2. Start the device scan.
3. Review the summary and individual findings.
4. Use search or the system-app option to refine the list when needed.
5. Select only items you recognize and intend to remove.
6. Read the confirmation prompt carefully before approving an action.

## Cleaning Detected Threats and Cache

1. Start the virus-cleaning function from the appropriate device area.
2. Review the live console while the tool checks installed applications against its threat records.
3. Confirm that detected viruses, malware, adware, or unwanted applications were removed or disabled successfully.
4. Allow the browser and temporary-cache cleanup stages to finish.
5. Review the final summary before disconnecting the device.

Browser cleanup can remove cache, cookies, sessions, and other locally stored browser information. Back up anything important and obtain the device owner's approval before continuing.

## Managing Customers

Open **Customers** to search and manage repair records. Select a record before editing its problem description, recording parts use, marking delivery, closing the case, or deleting the record.

## Managing Inventory

Open **Inventory** to search by model and review available displays, batteries, and UI boards. Record a part as used when it is installed, or use the stock controls to add and maintain inventory entries.

## During an Operation

- Keep the device connected until the operation finishes.
- Follow all messages displayed in the console.
- Do not start a second operation while another task is active.
- Use **Cancel Tool** when you need to stop a supported active task.

## Troubleshooting

- If no port appears, reconnect the device and refresh the port list.
- If a function is unavailable, confirm that the correct device category is selected.
- If a scan cannot start, confirm that the device is detected and ready for the selected function.
- If an operation fails, review the last console message before trying again.

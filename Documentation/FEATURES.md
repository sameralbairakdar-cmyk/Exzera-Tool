# Feature Overview

This page describes what users can do with Exzera Tool. Internal implementation details and connection methods are intentionally not documented.

## Device Information

Select an available device port and use **Read Info** to display supported device details. The device console shows live status messages and operation results.

## Organized Service Areas

The main interface groups available functions into dedicated areas:

- **Samsung** — supported Samsung information and service workflows.
- **Xiaomi** — supported Xiaomi account and service workflows.
- **Android** — general Android device review and maintenance functions.
- **MTK** — supported MediaTek device workflows.
- **Account** — account status and activation information.

The exact functions available may depend on the connected device and the user's account.

## Smart Security Scan

The security scanner reviews installed applications and presents results in a searchable list. It can show the application package, installation information, source, risk level, and detection reasons. Users remain in control of any removal action and can review selected items before confirming.

## Device Console

The live console provides operation messages, progress, and completion status. **Clear** removes the current console output, while **Cancel Tool** stops an active task when supported.

## Customer Management

The customer workspace helps service centers organize customer records and repair cases. Users can search records, edit the reported problem, mark a device as delivered, close a case, record parts usage, and remove obsolete records.

## Spare-Parts Inventory

Inventory management tracks common parts by device model, including displays, batteries, and UI boards. Users can search stock, record consumed parts, and add, edit, or delete inventory entries.

## Digital Analysis

The digital-analysis view presents operation progress, elapsed time, estimated remaining time, and completion status for supported analysis tasks.
